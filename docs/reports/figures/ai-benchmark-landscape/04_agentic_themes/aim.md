# Agentic theme signals

## Aim

Compare the six overlapping keyword probes applied to the agentic set.

## Data source

Titles and summaries of agentic-tagged artifacts in `data/snapshots/*.json`, scanned with the regular expressions in the generation script.

## Chart type

Horizontal bars fit the long theme names and preserve a common zero baseline.
